### Step-by-Step Breakdown

#### 1. Force H.264 in WebRTC SDP (Frontend & Backend)
We configure the SDP (Session Description Protocol) on the WebRTC connection to place `H264` as the highest priority codec:
* Browser will automatically encode using hardware-accelerated H.264 (NVENC/Intel QuickSync/Apple VideoToolbox).
* Ensures the video bitstream arrives in Annex-B / NAL unit format ready for RTMP without any decoding or transcoding.

#### 2. Python Multi-RTMP Manager (`python_app/core/rtmp_manager.py`)
A dedicated manager module that:
* Accepts an arbitrary list of RTMP targets (e.g., YouTube `rtmp://a.rtmp.youtube.com/live2/KEY`, Twitch `rtmp://live.twitch.tv/app/KEY`).
* Builds the single-encode/bypass FFmpeg command:
  ```bash
  ffmpeg -re -i [stream_pipe] \
    -c:v copy \
    -c:a aac -b:a 128k -ar 44100 \
    -f tee -map 0:v -map 0:a \
    "[f=flv:onfail=ignore]rtmp://url1/key1|[f=flv:onfail=ignore]rtmp://url2/key2"
  ```
* Monitors stream status, bitrate, connection health, and auto-restarts on network drops.

#### 3. REST & WebSocket Endpoints (`python_app/api/`)
* `GET /api/rtmp/targets` — List all configured RTMP channels.
* `POST /api/rtmp/targets` — Add a new destination (Name, Server URL, Stream Key, Enabled toggle).
* `DELETE /api/rtmp/targets/{id}` — Remove a channel.
* `POST /api/rtmp/start` / `POST /api/rtmp/stop` — Start/Stop broadcasting to all active channels simultaneously.

#### 4. Controller & Player UI Control Panel
* Add a **"Stream Destinations (Multi-RTMP)"** modal/dock in [`index.html`](file:///e:/MediaFlow_Engine/Brod_cast_App/index.html).
* Quick presets for YouTube, Twitch, Facebook, Kick, and Custom RTMP.
* One-click **"Go Live"** master button with live uptime timer, individual channel status indicators (🟢 Live / 🔴 Offline / ⚠️ Error), and stream key hiding for privacy.
